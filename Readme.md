
# Library Management System in C++

## About the Project
The Library Management System is a console-based C++ application developed to demonstrate Object-Oriented Programming (OOP) concepts. It provides basic operations for managing books, library members, librarians, and book transactions.

## Features
- Add and display books
- Register library members
- Display member information
- Register and display librarian information
- Issue books and check their availability
- Return issued books
- Calculate late return fines

## OOP Concepts Used
- Classes and Objects
- Inheritance
- Encapsulation
- Constructors
- Function Overriding
- Virtual Functions

## Technologies Used
- C++
- Standard Input/Output Library
- String Library
- Visual Studio Code
- GitHub

## How to Run
1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure a C++ compiler, such as GCC, is installed.
4. Compile the source file:

   g++ main.cpp -o library

5. Run the program:

   Windows:
   library.exe

   Linux/macOS:
   ./library

## Project Limitations
- Book, member, and librarian records are stored in memory.
- The program supports a limited number of records.
- Data is not saved permanently after the program closes.
- Each book has an availability status, but member-specific borrowing records are not maintained.
